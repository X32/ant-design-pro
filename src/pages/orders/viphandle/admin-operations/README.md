# 管理员操作面板

## 📋 功能概述

管理员操作面板提供以下核心功能：

1. **查询操作日志** - 查看所有超级管理员的VIP开通和金币调整记录
2. **开通VIP** - 为用户手动开通VIP订阅（支持自定义天数和智能续费）
3. **调整金币** - 为用户增加或减少金币余额

## 🔑 权限要求

- 需要**超级管理员权限**（`is_superuser = 1`）
- 非超级管理员访问会自动跳转到首页

## 🚀 功能说明

### 1. 操作日志查询

**筛选条件：**
- 操作类型：全部 / VIP开通 / 金币调整
- 日期范围：选择开始和结束日期

**显示内容：**
- 操作ID
- 操作类型（VIP开通 / 金币调整）
- 操作员邮箱
- 用户ID和邮箱
- 操作描述
- 数量（VIP为天数，金币为金币数）
- 原因/备注
- 操作时间

**统计数据：**
- 总操作次数
- VIP开通次数
- 累计发放金币
- 累计扣减金币

### 2. 开通VIP

**操作步骤：**
1. 点击"开通VIP"按钮
2. 输入用户邮箱（自动查询用户信息）
3. 选择VIP套餐
4. （可选）自定义天数（不填则使用套餐默认天数）
5. 填写开通原因（必填，审计用）
6. 确认提交

**功能特性：**
- ✅ 自动查询用户信息
- ✅ 显示套餐详情和价格
- ✅ 支持自定义天数（1-3650天）
- ✅ 智能续费（已有未过期订阅会自动延长）
- ✅ 跨级别开通支持
- ✅ 操作审计记录

**示例场景：**
- 客服补偿用户
- 活动赠送VIP
- 内部测试账号
- 异常订单补开通

### 3. 调整金币

**操作步骤：**
1. 点击"调整金币"按钮
2. 输入用户邮箱（自动查询钱包信息）
3. 输入调整金额（正数=增加，负数=减少）
4. 填写调整原因（必填，审计用）
5. 确认提交

**功能特性：**
- ✅ 自动查询用户钱包信息
- ✅ 显示当前余额和统计数据
- ✅ 实时计算调整后余额
- ✅ 防止余额为负的验证
- ✅ 二次确认防止误操作
- ✅ 操作审计记录

**钱包信息显示：**
- 用户ID
- 当前余额
- 冻结余额
- 累计充值
- 累计消费
- 交易次数

## 📊 API 接口

### 查询接口
- `GET /api/admin/operations/logs` - 查询操作日志
- `GET /api/admin/vip-plans` - 获取VIP套餐列表
- `GET /api/admin/wallets?user_email=xxx` - 查询用户钱包
- `GET /api/admin/wallets/{user_id}` - 获取钱包详情
- `GET /api/admin/operations/statistics` - 获取统计数据

### 操作接口
- `POST /api/admin/vip-subscriptions/grant` - 开通VIP
- `POST /api/admin/wallets/{user_id}/adjust` - 调整金币

详细API文档请参考：`/doc/ADMIN_OPERATIONS_API.md`

## 🛡️ 安全特性

1. **权限验证**
   - 所有接口都需要超级管理员权限
   - Token 失效自动跳转登录

2. **操作审计**
   - 所有操作都会记录在日志中
   - 包含操作员信息、原因、时间等

3. **数据验证**
   - 金币调整后余额不能为负
   - VIP开通天数限制（1-3650天）
   - 必填字段验证

4. **二次确认**
   - 金币调整需要二次确认
   - 显示详细的操作信息

## 🎯 使用建议

### 开通VIP
- **活动赠送**：使用标准套餐，备注"XX活动赠送"
- **客服补偿**：可自定义天数，备注具体补偿原因
- **测试账号**：选择短期套餐（如7天），备注"测试账号"

### 调整金币
- **系统补偿**：正数，备注具体补偿原因
- **异常退款**：正数，备注订单号和异常情况
- **违规扣款**：负数，备注违规原因（谨慎使用）

## 🔍 故障排查

### 1. 提示"需要超级管理员权限"

**原因**：当前登录用户不是超级管理员

**解决**：
```sql
-- 在数据库中设置超级用户
UPDATE users SET is_superuser = 1 WHERE email = 'admin@example.com';
```

### 2. 提示"未找到该用户"

**原因**：输入的邮箱不存在或拼写错误

**解决**：
- 检查邮箱拼写
- 确认用户是否已注册

### 3. 提示"调整后余额不能为负数"

**原因**：尝试扣除的金币超过用户当前余额

**解决**：
- 先查询用户当前余额
- 调整扣除金额

### 4. 提示"套餐不存在"

**原因**：选择的套餐已下架或被删除

**解决**：
- 刷新页面重新加载套餐列表
- 选择状态为"active"的套餐
